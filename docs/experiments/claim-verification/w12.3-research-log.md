# W12.3 independent claim-verification research log

## 2026-09-19 — scope and method

Issue #323 was re-read from the live tracker after W12.2 merged. Existing
`verification.py` and publication gates were inspected first. They correctly bind
fixture judgments to exact inputs but explicitly do not provide a semantic oracle
or authenticated model verifier. W12.3 therefore adds an isolated experimental
boundary instead of changing the publication path before value is established.

The research-methodology skill was applied as a technical verification study. The
durable destination is this tracked experiment package and its eventual evidence
packet. The corpus will preserve exact source spans and sealed judgments separately
from synthesis. Excluded runs, weak evidence, and inaccessible model routes will be
recorded here rather than silently discarded.

The primary verifier path is planned as a Hermes one-shot call pinned to a named
model route, separate from the deterministic control and sealed references. A
preflight outside the measured tree must establish the live route, exact output
contract, receipt capture, and failure behavior before freeze.
