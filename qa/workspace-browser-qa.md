# Workspace browser QA

Deterministic synthetic-only loopback APIs, independent nonpersistent Valkey
fixture and actual headless Chromium. No provider/GPU or production activity.

Passed before and after a full API-process restart:

- Select a completed independently retained root and inspect capability boundary.
- Resolve its cited source and view exact fictional evidence bytes.
- Reload selection by opaque root ID; server records remain authoritative.
- Resolve citations from the existing retained Valkey adapter after process loss.
- Another credential sees 404 and no private content.
- Delete selected root; 410 persists after reload.
- No private localStorage writes and no JavaScript exceptions.

Backend fixtures separately assert immutable revision conflicts, named operation
semantics, source quote references, cancellation of terminal roots, paging bounds,
and deletion of one root not blocking another. Portal fixtures verify bounded
named proxy methods, caller-scope forwarding, foreign-origin rejection and error
status preservation. PostgreSQL migration/replay/scope/expiry/deletion probes are
in the isolated Runtime CI storage lane; local browser QA is not a substitute.
